✦ DuckDuckGo Search
Static · No search API key

Search on your terms.

A simple search launch page. Your query is sent directly to DuckDuckGo in a separate tab, while this homepage stays open.

Searches are not saved by this page. DuckDuckGo receives the query, and your browser may keep normal history for the new tab.

Direct DuckDuckGo search

The form uses DuckDuckGo's HTTPS search URL and the standard q query parameter. No API key, search proxy, or backend is needed.

Separate tab, not a separate browser

Search results open in a new tab so this site remains open. A website cannot create a separate browser profile or guarantee isolation from your computer's browser history. For stronger local separation, use a separate browser profile or a private window.

No search history stored here

This static page has no search-history code, analytics, cookies, or local storage. It does not send the query to a server operated by this project.

Know where the query goes

When you submit a search, DuckDuckGo receives your query and normal connection metadata. See DuckDuckGo's privacy policy.

Hosted as a static GitHub Pages site. HTTPS protects the connection, but this page does not provide anonymity or isolate browser-level history.
